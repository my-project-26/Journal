4

Sync über GitHub

Mit einem GitHub-Token speichert das Journal deine Einträge zusätzlich in einem privaten Gist in deinem GitHub-Konto. Dann siehst du auf Mac und Handy dieselben Daten. Den Token gibst du auf jedem Gerät einmal ein.

So erstellst du den Token (einmalig, 2 Minuten)
  1. Auf github.com rechts oben auf dein Profilbild → Settings.
  2. Ganz unten links Developer settings → Personal access tokens → Tokens (classic).
  3. Generate new token (classic). Name: „Trading-Journal“. Ablauf: z. B. 1 Jahr.
  4. Bei den Rechten nur „gist“ ankreuzen, sonst nichts.
  5. Erstellen, den Token (beginnt mit ghp_) kopieren und unten einfügen.

Der Token darf nur Gists lesen und schreiben, nicht an deine Repositories. Er bleibt in diesem Browser gespeichert und wird nur an GitHub geschickt. Gib ihn niemandem weiter.

Sync ist aus. Einträge liegen nur in diesem Browser.

5

Sichern & übertragen

Ohne Sync liegen deine Einträge nur in diesem Browser. Sichere sie dann regelmäßig als Datei. Mit derselben Datei überträgst du sie auch ohne Sync auf ein anderes Gerät.
